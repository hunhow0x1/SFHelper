How SFHelper reads your account

To show your full inventory, arsenal, and loadouts, SFHelper reads a small piece of session data from the running Soulframe game — the same thing every Soulframe companion app has to do, because the game exposes no other way to get it.

SFHelper only ever reads the game's memory — it never writes to it. Reading is considered safe; writing is not, and this app is structurally incapable of it (its memory access is opened read-only, with no write path anywhere in the code). Still, only you can decide the risk for your account, so nothing runs until you agree below.

If you agree, the read-only helper runs automatically to import your inventory. You can revoke this at any time by clearing SFHelper's data. This choice is remembered.
